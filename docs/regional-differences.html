SMS Regional differences

What changed between the GameCube releases of Super Mario Sunshine: JP 1.0, US, JP 1.1, PAL and Korean. Every entry comes from the decompiled source, which is built once per release and checked against that release's own disc; a function hashed from each disc's disassembly says which release changed it, and a sweep of every remaining constant mismatch (hidden inside 98–100% functions) caught the last text numbers, sounds and timings. Each entry says what you would see in game, has a Hz note, and gives the code in a drop-down. What is left is listed at the end.

Click a line of code to open the source file that holds it. Grouped by release, in release order (JP 1.0, US, JP 1.1, PAL, Korean); each release lists only what changed from the release its code is based on (the one before it; for the Korean disc, a US build, that is US), and a change a later release drops is marked as a regression. Inside a release, by world in the order you reach them; something that happens in several worlds sits under the first one and names the others. The Hz notes matter for PAL, which inherits every earlier change. The 3D All-Stars build is not written up here.
